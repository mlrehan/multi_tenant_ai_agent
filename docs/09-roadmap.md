## Resuming work in a new session

1. Read [../CLAUDE.md](../CLAUDE.md) for the project summary and confirmed decisions.
2. Check this file for the next "Not started" phase.
3. Read the docs already produced for context — do not regenerate them.
4. Continue from the next phase only.
5. From Phase 5 onward, code exists and has a real dev environment: `docker compose -f docker-compose.dev.yml up -d` (Postgres + Redis), copy `.env.example` to `.env` (needs a generated RSA keypair for `JWT__PRIVATE_KEY_PEM`/`JWT__PUBLIC_KEY_PEM`, `\n`-escaped on one line — see `scripts/_gen_dev_env.py`), `pip install -e .[dev]`, `python -m alembic upgrade head`, then `python -m pytest`.
